# ADR #1: Django + DRF como Backend

## Contexto
Se necesita un framework robusto para construir una API REST con autenticación, validación y documentación automática.

## Decisión
Usar Django 5 + Django REST Framework como backend principal.

## Consecuencias
- ORM maduro y seguro
- Admin panel incluido
- Ecosistema amplio de paquetes
- Curva de aprendizaje moderada
